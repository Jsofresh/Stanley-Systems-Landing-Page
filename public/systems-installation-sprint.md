# Systems Installation Sprint

Canonical HTML page: https://stanley-systems.com/systems-installation-sprint

The Systems Installation Sprint is the optional done-for-you build after the Office Process Assessment. The Sprint is scoped after Stanley Systems reviews the office flow.

Systems Installation Sprint standard installation: $1,500. The Office Process Assessment sets the build scope. Stanley Systems installs the approved systems inside the buyer’s current tools.

The Sprint can install faster billing, cleaner follow-up, review requests, referral tracking, repeat-customer reminders, or the specific mix the business needs.

The Sprint is complete when the approved systems are set up, tested, and running inside the current tools, so they are live in the office workflow.
