# Higgsfield Request: cashflow-green-cash-arrow

## 1. Asset name

cashflow-green-cash-arrow

## 2. Intended website use

Decorative textless foreground/right-side layer inside the Cashflow Control System visual card. It sits at the end of the DOM/SVG-built cash pipeline, behind or beside the final `Collected Cash` stage. Codex will overlay all labels, icons, stage nodes, badges, cards, and text separately.

## 3. What the image is

A clean green right-pointing collected-cash arrow with a polished translucent/glass feel, a few small floating bill shapes, soft green glow, and subtle website-asset depth.

## 4. What the image is not

Not a full website section. Not a UI mockup. Not a chart. Not a dashboard. Not a logo. Not a button. Not a literal pile of money spilling everywhere. Not a cartoon. Not stock art. Not a final pipeline diagram.

## 5. Visual story

The repaired cashflow pipeline ends with collected cash moving forward.

## 6. Exact visible objects

- one large right-pointing green arrow
- soft green glow around the arrow
- three to five small floating green bill shapes
- two to four tiny green sparkle marks
- subtle white highlights on the arrow
- transparent surrounding space
- no text
- no icons with letters or numbers

## 7. Composition

Arrow points left to right. Keep the arrow centered vertically. Leave transparent padding around all sides so Codex can position it inside a white rounded card. The left edge should be visually easy to connect to a DOM/SVG pipe. The right edge can extend slightly with glow, but keep the object compact enough to sit in the right 20 percent of a desktop visual card.

## 8. Style

Crisp vector-style website asset, premium light-mode UI illustration, clean edges, subtle depth, soft gradients, modern landing page asset, polished SaaS-quality but not generic, no fuzzy texture.

## 9. Palette

Stanley green, pale green, white highlights, very soft gray shadow. No orange, amber, tan, brown, purple, neon colors, black background, or dark mode.

## 10. Text rule

No readable text. No letters. No numbers. No labels. No UI copy. No fake text. No watermark.

## 11. Integration rule

The real website text and icons will be overlaid by React components. Leave clean safe areas for DOM overlays. This asset is decorative only.

## 12. Negative prompt

No people, no robots, no office scene, no full webpage, no UI cards, no text, no numbers, no letters, no watermark, no orange, no amber, no tan, no brown, no purple, no black background, no dark mode, no realistic cash photo, no messy money spill, no clip art, no stock illustration, no random icons, no 3D cartoon style, no cryptocurrency style, no charts, no magnifying glasses, no gears.

## 13. Output requirements

Transparent PNG if available, high resolution, clean edges, no watermark, no text, usable as a website layer. Prefer 16:9-ish or wide horizontal proportions with transparent background.

## 14. Rejection criteria

Reject if it contains text, fake text, numbers, a dark background, orange/amber/tan tones, people, random icons, messy cash piles, coins/charts/gears, hard-to-crop edges, or looks like stock art.
