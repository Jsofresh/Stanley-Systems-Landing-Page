# Higgsfield Request: customer-revenue-green-arrow

## 1. Asset name

customer-revenue-green-arrow

## 2. Intended website use

Decorative textless right-side layer inside the Repeat Revenue System visual card. It sits behind or beside the DOM-built outcome badge cluster to show revenue momentum. Codex will build all node labels, outcome labels, support cards, CTAs, connector lines, and text separately.

## 3. What the image is

A clean green right-pointing revenue arrow with a soft glow, subtle glass gradient, a few small floating green bill shapes, and restrained sparkle accents.

## 4. What the image is not

Not a full website section. Not a full flywheel diagram. Not a chart. Not a dashboard. Not a logo. Not a CTA button. Not a stock finance illustration. Not a crypto graphic. Not a UI card.

## 5. Visual story

Customer moments turn into forward revenue momentum.

## 6. Exact visible objects

- one large right-pointing green arrow
- soft green glow trailing behind the arrow
- three to five small floating green bill shapes
- two to four tiny green sparkle marks
- soft white highlights
- clean transparent surrounding space
- no text
- no labels
- no numbers
- no icons with letters

## 7. Composition

Wide horizontal composition. Arrow points left to right. Keep left side open enough to sit near DOM outcome badges. Keep transparent padding around all edges. The asset should work in the right 30 to 35 percent of a desktop visual card without covering readable DOM text.

## 8. Style

Crisp vector-style website asset, premium light-mode UI illustration, clean edges, subtle depth, soft gradients, modern landing page asset, polished but not flashy, no stock illustration feel.

## 9. Palette

Stanley green, pale green, white highlights, very soft gray/blue shadows. No orange, amber, tan, brown, purple, neon colors, black background, or dark mode.

## 10. Text rule

No readable text. No letters. No numbers. No labels. No UI copy. No fake text. No watermark.

## 11. Integration rule

The real website text, outcome badges, icons, flywheel nodes, and connector lines will be DOM/SVG elements. This asset is decorative only. Leave clean safe areas for DOM overlays.

## 12. Negative prompt

No people, no robots, no office scene, no full webpage, no UI cards, no text, no numbers, no letters, no watermark, no orange, no amber, no tan, no brown, no black background, no dark mode, no neon crypto style, no realistic cash photo, no messy money spill, no clip art, no stock illustration, no random icons, no charts, no gears, no magnifying glasses, no 3D cartoon style.

## 13. Output requirements

Transparent PNG if available, high resolution, clean edges, no watermark, no text, usable as a website layer. Prefer wide horizontal proportions.

## 14. Rejection criteria

Reject if it contains text/fake text/numbers, has a dark background, uses orange/amber/tan/purple, looks like crypto/neon art, includes people/random icons/charts, is too busy, or cannot sit behind DOM outcome badges.
