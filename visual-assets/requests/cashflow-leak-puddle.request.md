# Higgsfield Request: cashflow-leak-puddle

## 1. Asset name

cashflow-leak-puddle

## 2. Intended website use

Small decorative textless leak/drip/puddle layer inside the Cash Flow Collection System visual card. It sits under DOM/SVG pipe joints near leak warnings. Codex will build all warning badges, labels, dashed connectors, pipeline stages, and text separately.

## 3. What the image is

A small clean red leak accent: two or three simple drip shapes falling from an invisible pipe edge into a tiny polished puddle, designed as a premium website decoration.

## 4. What the image is not

Not a full pipeline. Not a full website section. Not a money spill. Not blood. Not a messy liquid scene. Not a warning badge. Not a label. Not a UI card. Not a photo. Not a cartoon sticker.

## 5. Visual story

A small visible leak marks where the cashflow process breaks down.

## 6. Exact visible objects

- two or three small red drip shapes
- one tiny red/pale-red puddle
- subtle soft shadow under the puddle
- clean transparent surrounding space
- no pipe unless it is only a tiny abstract gray edge with no labels
- no text
- no numbers
- no icons

## 7. Composition

Compact vertical accent. Keep the total asset small with transparent padding. It should fit under a pipe joint without blocking DOM labels. Keep the top visually simple so Codex can align it under a dashed warning connector.

## 8. Style

Crisp vector-style website asset, premium light-mode UI illustration, clean edges, subtle depth, soft gradients, modern landing page asset, restrained and practical.

## 9. Palette

Clear warning red and pale red only, with a very soft gray shadow if needed. No orange, amber, tan, brown, purple, neon colors, black background, or dark mode.

## 10. Text rule

No readable text. No letters. No numbers. No labels. No UI copy. No fake text. No watermark.

## 11. Integration rule

The real website warning labels, icons, badges, stage labels, and pipe structure will be DOM/SVG elements. This asset is decorative only and must leave clean space for overlays.

## 12. Negative prompt

No people, no robots, no money piles, no coins, no charts, no full webpage, no UI cards, no labels, no letters, no numbers, no watermark, no orange, no amber, no tan, no brown, no black background, no dark mode, no blood, no horror, no realistic liquid photo, no messy spill, no clip art, no random icons, no gears, no magnifying glasses.

## 13. Output requirements

Transparent PNG, high resolution, clean edges, no watermark, no text. Asset should be compact and easy to place as a small website layer.

## 14. Rejection criteria

Reject if it looks like blood, contains text/fake text, is too large or chaotic, includes money piles/coins/charts/people, uses orange/amber/tan tones, has a dark background, or looks like stock clip art.
