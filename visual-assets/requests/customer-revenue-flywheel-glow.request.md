# Higgsfield Request: customer-revenue-flywheel-glow

## 1. Asset name

customer-revenue-flywheel-glow

## 2. Intended website use

Decorative background layer behind the DOM/SVG-built Customer Revenue flywheel nodes. It sits inside the large Customer Revenue System visual card, behind the center hub and four outer nodes. Codex will build all circles, labels, icons, arrows, and text as DOM/SVG.

## 3. What the image is

A soft circular pale-green glow and subtle ring system that gives a four-node flywheel diagram depth without becoming the diagram itself.

## 4. What the image is not

Not a complete flywheel diagram. Not a full UI. Not a chart. Not a dashboard. Not a logo. Not a background with text. Not a node system. Not an icon set. Not a neon ring.

## 5. Visual story

A clean customer revenue loop has gentle momentum and depth.

## 6. Exact visible objects

- soft circular green ring glow
- subtle radial highlight
- faint circular motion impression
- pale green low-contrast depth
- transparent background
- no node circles with labels
- no icons
- no arrows with labels
- no text
- no numbers

## 7. Composition

Centered circular glow. Transparent background. Keep the center clean enough for a DOM center circle to sit on top. Keep outer edges soft and low contrast. The asset should sit behind a roughly 420 to 470px desktop flywheel and scale down cleanly.

## 8. Style

Crisp vector-style website asset, premium light-mode UI illustration, clean soft edges, subtle depth, soft gradients, modern landing page asset, not flashy, not stock art.

## 9. Palette

Pale green, Stanley green at low opacity, white, soft gray/blue shadow. No orange, amber, tan, brown, purple, neon colors, black background, or dark mode.

## 10. Text rule

No readable text. No letters. No numbers. No labels. No UI copy. No fake text. No watermark.

## 11. Integration rule

The real website nodes, labels, icons, arrows, and hub text will be DOM/SVG elements placed on top. This asset is only a background glow layer. Leave clean safe areas for DOM overlays.

## 12. Negative prompt

No people, no robots, no dashboard, no UI cards, no text, no icons, no numbers, no letters, no watermark, no orange, no amber, no tan, no brown, no black background, no dark mode, no neon glow, no crypto style, no stock art, no messy texture, no hard ring outlines, no complete diagram, no node labels, no charts, no gears, no stars.

## 13. Output requirements

Transparent PNG, high resolution, soft edges, no watermark, no text. Square or near-square composition preferred.

## 14. Rejection criteria

Reject if it contains text/fake text, obvious icons, node labels, orange/amber/tan/purple, dark background, neon/crypto styling, hard distracting rings, or competes with DOM nodes.
